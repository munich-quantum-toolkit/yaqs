# Individual-gate benchmarks

This self-contained campaign supplies Figure 1 and the quoted single-gate
variational-MPO comparison.

## Protocol

| Quantity | Value |
| --- | --- |
| Sites | \(N=12\) |
| Gate sites | code \((1,10)\), manuscript \((2,11)\) |
| Seeds | \(11,22,33\) |
| Bond profile | \([1,2,4,8,8,8,8,8,8,8,4,2,1]\) |
| Pauli/CNOT production caps | \(8,16\) |
| CNOT rank-sweep caps | \(8,10,12,14,16\) |
| Production SVD threshold | \(10^{-13}\) |
| Effective-zero threshold | \(10^{-300}\) |
| Krylov tolerance | \(10^{-12}\) |

The methods are gate-local two-site TDVP, MPO contract-and-truncate, and
TEBD+SWAP. Dense application of the same gate supplies the reference. The
variational control fits the normalized uncompressed MPO-applied state.

The CNOT generator path is
\[
H_{\mathrm{CX}}=(\pi/4)(I-Z_c)\otimes(I-X_t),\qquad
U(s)=e^{-isH_{\mathrm{CX}}}.
\]
TDVP substeps partition this path; they are not fractional CNOT gates.

## Reproduce

```bash
uv run python experiments/individual_gates/run.py --stage all
uv run python experiments/individual_gates/rxx_refinement_comparison.py
uv run python experiments/individual_gates/variational_control.py
uv run python experiments/individual_gates/analyze.py
uv run python experiments/individual_gates/plot.py
```

The portable source data retained under `output/` are the campaign and CNOT
rank rows, the CNOT and \(R_{XX}\) refinement rows, the variational-MPO rows,
and their compact validation and analysis summaries. State snapshots and
content-addressed task caches are regenerated by the drivers and are not
stored.

```bash
uv run pytest -n 0 \
  experiments/individual_gates/test_individual_gates.py \
  tests/experiments/test_single_gate_repairs.py -q
```
